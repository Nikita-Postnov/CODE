# План безопасного развития NP Notes

Статус: проектирование оставшихся функций, **не означает, что они реализованы**. Рабочая ветка `main` и формат `Data` не меняются до ручной проверки.

## 1. Восстановление несохранённых правок

- Текущий путь: `noteapp/app/autosave.py`, `persistence.py`.
- Уже добавлено: повтор после ошибки записи с сохранением признака несохранённого текста.
- Дальше: журнал восстановления с atomic write и TTL, привязанный к UUID заметки, фиксировать оригинальную версию и не восстанавливать старые правки поверх новых.
- При старте показывать восстановление только если журнал новее сохранённой заметки; пользователь может принять или отклонить.
- Тесты: внезапный kill, выключение питания между записью и rename, переполнение диска, два запуска приложения, откат восстановления.

## 2. Защита конфиденциальных данных

- Существующее поле `password_manager` может содержать текст; автоматическое шифрование текущих файлов **не включено**.
- Спроектировать versioned envelope с Windows DPAPI для секретных полей и явно обрабатывать ситуацию, когда другой ПК / профиль не может расшифровать данные.
- До миграции: выбор способа резервного копирования, явно согласованный экспорт, невозможность тихой потери данных.
- Тесты: чтение legacy, round-trip на Windows, перенос на другой профиль, отмена миграции, повреждённый зашифрованный payload, восстановление из backup.
- Не хранить DPAPI ключ, токен или пароль внутри репозитория.

## 3. Организация заметок

- Сначала проверить действующие теги, избранное, закрепление и сортировку.
- Предлагаемый новый UX: избранное / недавние / без тегов как виртуальные представления (без изменения схемы JSON); только после этого реальные папки, если они необходимы.
- Тесты: одинаковые заголовки, 10 000 заметок, удалённый тег, перенос между фильтрами без изменения UUID.

## 4. Редактор

- Уже имеются rich text, таблицы, checkbox, ссылки и заголовки; не дублировать.
- Следующие задачи: горячие клавиши, доступная навигация и Undo/Redo для операций над таблицами, точечное выделение найденного.
- Тесты с Qt: сохранение/загрузка HTML, выделение, undo, вставка Unicode, изображения, авто-ссылки.

## 5. Виджет на рабочем столе

- Добавлено: копирование текста через контекстное меню без изменения хранилища.
- Дальше: опциональное отключение «поверх окон» и настройки непрозрачности с сохранением в QSettings, проверка на нескольких мониторах.
- Тесты: повторный запуск, смена DPI, недоступный экран, закрытие во время записи.

## 6. Производительность

- Добавлено: поиск «Везде» выполняет быструю проверку метаданных до преобразования HTML.
- Дальше: измерение времени старта, открытия заметки и поиска на 100 / 1 000 / 10 000 заметок, без содержимого пользовательских файлов в телеметрии.
- Оптимизировать только после исходных и итоговых измерений.

## Критерии объединения в main

1. Windows + Linux CI зелёный, включая тесты переносимости и сохранения.
2. Ручной Qt smoke test под Windows 11.
3. Пробный запуск на анонимизированной копии Data; сравнение файлов и обратная совместимость.
4. Отдельный backup Data до первого обновления; проверенный rollback Choice.
5. До успешной проверки PR остаётся черновиком и не сливается автоматически.
