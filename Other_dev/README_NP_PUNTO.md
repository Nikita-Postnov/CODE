# NP Punto — безопасность и настройки

Портативный скрипт: `Other_dev/punto_like_work_safe.py`.

## Сохранившиеся функции

Ручное исправление раскладки, изменение регистра, правила автозамены, история буфера (текст и изображения), трей, исключение приложений, автоматическое восстановление после сбоя и другие функции предыдущей версии сохранены.

## Что изменилось

- **Буфер обмена.** Если не удалось сохранить полный набор переносимых форматов, преобразование выделения отменяется. Данные, скопированные другим приложением во время конвертации, не перезаписываются возвратом старого буфера. Смена Clipboard Sequence Number между снимком и операцией также отменяет действие. Неизвестные форматы OLE/GDI, которые нельзя корректно сохранить, блокируют преобразование через буфер; это безопаснее потери данных.
- **Choice.** При наличии переменной окружения `CHOICE_PID` Punto не запускает отдельный `NP_Punto.exe` вне контроля лаунчера. Остановка приложения в Choice должна останавливать его вместе с рабочим процессом.
- **Клавиатура.** Операция после пробела передаётся worker без ожидания в глобальном хуке; отменяется, если пользователь уже продолжил ввод, сменил активное окно или фокус. При высокой скорости ввода правило может быть пропущено, но не должно исправлять устаревшее содержимое.
- **Горячие клавиши.** Из резервных сочетаний отмены удалён обычный `Ctrl+Z`, чтобы не перехватывать стандартное Undo в редакторах.
- **Резервные копии.** Настройки и правила атомарно сохраняются с файлом `.bak`. Если текущий JSON повреждён, используется предыдущая корректная копия. Невосстановимые файлы не удаляются.
- **Автоматическая раскладка.** Осторожное исправление по редактируемому словарю выключено по умолчанию. Работает только при совпадении результата преобразования со словом из словаря, в стандартных Edit/RichEdit-полях и только после пробела. Существующие правила замены применяются первыми. Функция не использует искусственный интеллект и не делает предположения по неизвестным словам.

## Включение необязательной автокоррекции

1. Открыть меню значка NP Punto в трее → «Открыть файл настроек (хоткеи, лимиты)».
2. В `Data/punto_like_settings.json` выставить `"auto_layout_correction": true`.
3. В меню трея выбрать «Словарь исправления раскладки» и добавить желаемые слова по одному на строку (например, `привет`, `спасибо`).
4. Перезапустить NP Punto через Choice.

Словарь расположен в `Data/punto_like_layout_words.txt`. По умолчанию функция отключена. Чтобы отключить снова, выставить `false`.

## Тестирование

`python -m unittest -v tests/test_np_punto_reliability.py`

Сценарии автоматизированных проверок охватывают восстановление конфигурации, безопасный буфер, конфликтные сочетания, асинхронную обработку пробела и распознавание слов в неверной раскладке. Поскольку реальное взаимодействие с чужими окнами зависит от конкретной версии Windows и приложений, перед постоянным использованием проверь работу в Блокноте, браузере, редакторе кода и программе с нестандартным буфером.


## Если NP_Punto перестал реагировать

1. Через Choice остановите и заново запустите `punto_like_work_safe.py`.
2. В меню трея выберите «Проверить состояние NP_Punto». Показываются факт паузы, ограничение одним окном, исключения для активного приложения, состояние автокоррекции, число слов словаря и работоспособность фоновых потоков; вводимый текст не считывается.
3. Если включена пауза или режим одного окна, выберите «Возобновить работу во всех окнах». Список исключений этим действием **не изменяется**.
4. Если диагностика сообщает «Исключено: ДА», включите обработку в соответствующем приложении через пункт трея.
5. При сохранении неисправности проверьте журнал `Data/punto_like_sess*.log` (имя определяется сессией Windows) и `Data/punto_like_fault*.log`.

Если Windows или другое приложение заняло часть горячих клавиш, NP_Punto продолжает выполнять доступные функции и автокоррекцию. Список недоступных сочетаний указывается в диагностике. Программа также проверяет жизнеспособность фоновых потоков и при их неожиданной остановке перезапускает их; зависшие нативные вызовы требуют обычного перезапуска через Choice.
