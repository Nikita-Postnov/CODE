# NP Language Indicator — настройка и обновление

Индикатор текущей раскладки Windows. Поддерживаются RU/EN и другие языки,
несколько мониторов, разные DPI и запуск через Choice.

## Обновление

Остановить `Language_indicator.py` в Choice, выбрать «Обновить скрипт с GitHub»,
затем запустить снова. Для работы необходим PyQt6 в используемом Runtime.

При запуске через Choice скрипт больше не отделяется от лаунчера.
Пункт «Перезапустить скрипт» в этом режиме повторно загружает настройки
и пересоздаёт индикаторы **внутри прежнего процесса**.

## Меню трея

В разделе «Настройки» доступны:
- включение/выключение большой плашки при смене раскладки;
- отдельное разрешение большой плашки при переключении между окнами;
- выбор только основного монитора, размещения на панели задач или в углах;
- выбор длительности и размера всплывающей плашки и маленьких индикаторов;
- изменение цветов RU, EN и фонов;
- восстановление заводских настроек.

«Скрыть/показать индикаторы» сохраняет выбор между запусками.
«Перезагрузить настройки из файла» повторно читает JSON без выхода.

## Файлы

Настройки: `Data/language_indicator_settings.json` рядом со скриптом.
Перед перезаписью предыдущий корректный JSON копируется в
`Data/language_indicator_settings.json.bak`. При повреждении основного
файла программа использует резервную копию.

Журнал: `Data/language_indicator_error.log` (ротация 1 МБ и две копии).
Набираемый текст и нажатия клавиш не пишутся; регистрируется только
изменение раскладки, фокуса, настройки и ошибки.

## Работа с NP_Punto

Language Indicator не меняет текст или раскладку сам, а считывает фактическую
раскладку текущего окна. При автокоррекции со сменой раскладки в NP_Punto
индикатор обновляется при следующей проверке (обычно не позднее 100 мс).

При переключении между окнами с разными раскладками маленькая плашка
обновится, но крупное уведомление по умолчанию не появится.
Позиционирование окон и восстановление Z-порядка выполняются существенно
реже опроса раскладки, обычно раз в 2 секунды.

## Проверки

GitHub Actions выполняют тесты JSON, резервной копии, настроек и синтаксиса
на Windows и Linux, а также импорт PyQt6-модуля на Windows.
Проверки реального расположения на разных мониторах требуют локального теста.
