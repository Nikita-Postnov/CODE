# NP Punto Browser — дополнение для Chrome и Edge

Это отдельное **локальное** расширение для обычных полей HTML (input type=text/search,
textarea и простых одноузловых contenteditable). Оно дополняет NP Punto, который
обрабатывает стандартные поля Windows и ручные сочетания на уровне ОС.

## Ctrl+Ins в веб-полях (версия 1.0.2)

- **Ctrl+Ins** исправляет выделенный текст или фрагмент перед курсором,
  когда браузер получает это сочетание.
- **Ctrl+Alt+Shift+F8** — резервное сочетание с тем же действием.
- **Alt+Shift+Backspace** — безопасная отмена последней замены.

**Если запущен настольный NP Punto**, его глобальная регистрация Ctrl+Ins
может перехватывать сочетание до Chrome. Чтобы направить его расширению:

1. Обновите настольный NP Punto через Choice и перезапустите его.
2. Нажмите правой кнопкой на значке NP Punto в системном трее.
3. Включите **«Ctrl+Ins в Chrome/Edge через расширение»**.
4. Обновите расширение на `chrome://extensions`, обновите вкладку ChatGPT
   и проверьте: `ghbdtn` → `привет` по Ctrl+Ins.

Переключатель сохраняется в `Data/punto_like_settings.json` как
`browser_extension_hotkey_bridge`. По умолчанию выключен, чтобы не
изменять работу без установленного расширения. В Windows-приложениях
сохраняется прежняя обработка Ctrl+Ins.

Ручная конвертация работает без включения автоматической коррекции.
Комплексные редакторы с несколькими текстовыми узлами остаются ограничением.

## Исправление текста в ChatGPT (версия 1.0.1)

В поле ввода ChatGPT (ProseMirror/contenteditable) исправление теперь идёт
через штатную команду ввода редактора. Добавлены частые слова «что», «теперь»,
«умеет» и знаки EN Shift-раскладки, включая `&` → `?`.

Пример: `xnj ntgthm evttn&` → `что теперь умеет?`. Исправление
выполняется при вводе завершающего пробела или знака препинания. Уже
написанный текст можно исправить вручную: выделить текст и нажать
**Ctrl+Alt+Shift+F8**.

**Для работы в ChatGPT браузерное расширение должно быть установлено
отдельно, включено в Chrome/Edge и разрешено на chatgpt.com.** Обновление
настольного скрипта из Choice само по себе не устанавливает расширение.

После замены файлов расширения откройте `chrome://extensions` → **Обновить**,
а затем перезагрузите вкладку ChatGPT. В настройках расширения включите
**«Автоматически исправлять»**. Дополнительные правки словаря не нужны
для указанной фразы.

Работу внутри живого интерфейса ChatGPT стоит дополнительно проверить:
автотесты проверяют модель HTML-редактора, а не запущенный сайт.

## Установка

1. Обновить репозиторий CODE через Choice или GitHub.
2. Открыть в Chrome `chrome://extensions` или в Edge `edge://extensions`.
3. Включить **Режим разработчика** и выбрать **Загрузить распакованное расширение**.
4. Указать папку `Other_dev/NP_Punto_Browser` в локальной копии репозитория.
5. Открыть **Параметры расширения NP Punto Browser** и включить автокоррекцию.
6. В параметрах проверить/добавить слова и сайты-исключения.

При обновлениях кода расширения нажимать **Обновить** на странице расширений.
Загрузка через Choice обновляет файлы, но браузер не перечитывает распакованное
расширение автоматически.

## Возможности

- Исправление известных слов EN/RU **перед** вводом пробела или `, . ! ? ; :`.
  Отдельный механизм `beforeinput` работает синхронно и не теряет исправление
  при быстром следующем нажатии.
- **Ctrl+Ins** или **Ctrl+Alt+Shift+F8** — исправить выделение или текст перед курсором.
  Поддерживаются обычные поля и фрагменты одного текстового узла.
- **Alt+Shift+Backspace** — безопасно вернуть последнее изменение в том же
  поле, если текст и позиция курсора ещё совпадают.
- Редактор пользовательских правил, словарь, исключения по сайтам.
- Дополнительное запоминание вручную исправленных слов. Выключено по умолчанию.
- Без запросов к внешним API; настройки и выученные слова — в `chrome.storage.local`.
  Вводимый текст и история фраз никуда не передаются.
- Настройки автоматического исправления **выключены по умолчанию** для защиты
  от неожиданных изменений в чужих формах; ручная функция доступна сразу.

## Безопасность и ограничения

- Расширение запрашивает доступ к страницам, поскольку должно получать
  события ввода в HTML-полях. Код поставляется открытым для проверки.
- Поля паролей, одноразовых кодов, платёжных данных, email, URL, телефонные
  и числовые поля исключены. Отключаются также поля `readonly`, `pre`,
  `code` и зоны с `data-np-punto-off`. Для чувствительных веб-приложений
  добавляйте домены в список исключений.
- Сложные редакторы (Google Docs, Monaco/CodeMirror, canvas, редакторы с
  нестандартными DOM-событиями, редакторы с несколькими текстовыми узлами),
  закрытые браузерные страницы и части Shadow DOM могут не поддерживаться.
- Используется локальный словарь, а не облачная нейросеть. Автокоррекция
  выполняется **только при точном совпадении** с известным словом. Для
  неизвестных или неоднозначных слов используйте ручное сочетание.
- Расширение не меняет системную раскладку Windows. Для этого по-прежнему
  работает настольный NP Punto.
- После обновления самого скрипта Windows перезапустите его через Choice,
  а после обновления расширения нажмите **Обновить** в браузере.
